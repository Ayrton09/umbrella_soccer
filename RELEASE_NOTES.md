# Umbrella Soccer 1.0.0

Initial stable release for Counter-Strike: Source.

## Included

- Umbrella Soccer plugin version `1.0.0`.
- Source file and compiled plugin.
- Full translation file.
- Default configuration file.
- Default Umbrella Soccer player skins.
- Official ball model: `models/ayrton09/fifa_trionda_2026/trionda_2026.mdl`.
- Official map: `maps/ka_soccer_world_cup_2026.bsp`.
- FastDL package with compressed `materials`, `models`, and `maps`.

## Assets

- `umbrella_soccer-1.0.0-server.zip`: server package for the `cstrike` folder.
- `umbrella_soccer-1.0.0-fastdl.zip`: web-host package for FastDL.
- `SHA256SUMS.txt`: checksums for release files.

## Installation

Extract `umbrella_soccer-1.0.0-server.zip` into the server `cstrike` folder.

Extract `umbrella_soccer-1.0.0-fastdl.zip` into the root folder used by `sv_downloadurl`.

## Notes

Some store/player-skin plugins can override soccer skins. If players keep their store skin instead of the soccer skin, unload or disable that skin system on soccer maps.
